#Sealy

##A smol corner of the world wide web dedicated to seals and sea lions. (and addicts, like me)

Heyy! Welcome to Sealy.

Sealy is an educative website about my problematic obsession, SEALS AND SEA LIONS, build with React, TS, Vite and an unresonable ammount of curiosity + dedication and nonetheless, loyalty towards SEALS.

The big picture is pretty simple: create a place where people can learn about these wonderfull creatures without feeling like they're reading a 200-page biology textpaper along side maybe we start a cult here :).

I'm trying to make it informative, interactive and actually enjoyable to exlpore. Whether you're here to learn the differences between seals and sea lions, adorable marine mammals or looking for like minded individuals who can't seem to wrap their head around so they embrace it, you're welcome.

And yeah, I am aware that I could have chosen a more normal obession.

##How the Project Is Structured

The applications use reusable React comps, organized into separate files.

App.tsx acts as the root app component. It brings elements such as the announcemnt bar, nav bar and the shared `<main>` element that contains the current page.

The homepage is managed by pages/home.tsx, separatly, while components like the hero, navbar and icons have their own files.

##1. Clone the repo
```sh
git clone https://github.com/zzianis-stack/sealy.git
cd Sealy
```

##2. Install dependencies
`npm install`

##3. Start the development server
`npm run dev`
Open the local address Vite displays, usually http://localhost:5173/.

##4. Build for production
`npm run build`
The production files will be generated inside the dist/ folder.

##5. Preview the build
`npm run preview`
Congrats. You're now running a website dedicated to animals that spend toooo much time of their lives doing absolutely nothing.
